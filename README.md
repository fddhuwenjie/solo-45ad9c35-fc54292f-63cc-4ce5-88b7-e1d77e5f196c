# 无障碍影视解说编排台（本地 Web 应用）

面向无障碍影视解说编排的本地工具：导入 SRT 字幕后自动发现对白之间的静默窗口，
在同一时间轴上拖拽编排中英文解说卡片，实时检测冲突、估算朗读时长，并可倍速预演、
锁定片段、撤销调整、保存多个工作版本，最终导出解说 SRT 或与原字幕合并的 SRT。

**所有数据与处理均在本机完成，不依赖任何外部账号或在线 API。**

## 功能一览

- **SRT 导入**：支持选择本地文件或直接粘贴；容忍 BOM、CRLF、点号毫秒、缺失序号；可替换或追加。
- **静默窗口发现**：合并相邻/重叠对白后，按可调的「最小静默间隔」标出可插入空档，点击空档即可建卡。
- **三轨时间轴**：对白 / 空档 / 解说同一时间轴展示；多段重叠时自动分泳道；支持缩放（含 Ctrl+滚轮）。
- **解说卡片**：
  - 中英文混排文本；朗读时长按可配置语速估算（**每个汉字/假名 1 个朗读单位，每个英文词 1 个单位**）；
  - 「自动时长」跟随语速，或切「手动时长」自行指定；
  - 在时间轴上**整体拖动**或**拖左右边缘**精确改变起止（按住 Shift 以 10ms 微调，默认吸附 0.1s）；
  - 也可在编辑面板用 `时:分:秒.毫秒` / `分:秒` / 纯秒数精确输入开始、结束、时长。
- **实时冲突检测**：
  - 🔴 与对白重叠、与其他解说重叠；
  - 🔴 超出静默窗口：提示超出秒数、窗口余量、**建议缩短的朗读单位（字符/词）数**，并可一键缩短文本；
  - 🟡 余量过紧、文本可能念不完 / 区间过长可能冷场等提示；
  - 顶部统计栏汇总冲突 / 注意数量。
- **预演**：播放头从当前位置按 **0.5×–2× 倍速**推进（空格键播放/暂停），按时间顺序高亮当前对白与解说；
  点击标尺/轨道可跳转播放头。
- **锁定**：已确认片段可锁定，锁定后拒绝任何修改（接口层同样拦截），需先解锁。
- **撤销**：每次修改前自动快照（拖拽与连续输入做 5 秒合并），可逐步回退，最多保留 60 步。
- **工作版本**：随时把当前状态命名保存为版本，随时恢复（恢复前自动留快照，可撤销）。
- **导出**：
  - 只含解说的 SRT；
  - 解说 + 原字幕的合并 SRT（解说条目带 `【解说】` 前缀，全部条目重新按时间编号）；
  - UTF-8 BOM 编码，兼容常见播放器。
- **多项目**：可新建、重命名、删除多个项目，数据保存在本机 SQLite。

## 快速开始

需要 Python 3.8+。

```bash
# 方式一：自动脚本（缺 Flask 时会装到项目内 .pylibs，不需要 sudo）
bash run.sh

# 方式二：已自行安装 flask（pip install flask）后直接运行
python3 app.py
```

启动后浏览器访问 <http://127.0.0.1:5000>，点击「载入示例字幕体验」即可快速试用。

数据文件 `data.db` 位于项目目录，删除即清空全部数据；建议定期自行备份该文件。

## 目录结构

```
app.py              # Flask 后端：SRT 解析、冲突所需的区间数据、持久化、导出
data.db             # 运行后自动生成的 SQLite 数据库
static/
  index.html        # 单页界面
  style.css         # 样式
  app.js            # 时间轴渲染、拖拽、冲突分析、播放预演、版本/撤销交互
run.sh / bootstrap.sh  # 本地启动与依赖引导脚本
requirements.txt
```

## 朗读时长口径

默认语速 240 个朗读单位 / 分钟（可在顶部调整，实时重算全部自动卡片）：

- 汉字、假名等 CJK 字符：每个计 1；
- 连续的英文字母/数字（单词）：每段计 1；
- 标点与空白不计。

例：`"Hello 世界"` = 1 个英文词 + 2 个汉字 = 3 个单位，240 单位/分时约 0.75 秒。

## 数据与隐私

- 后端只监听 `127.0.0.1`，不对外网开放；
- 不发起任何外部网络请求，不加载第三方字体/脚本/统计代码；
- 字幕与解说仅写入本地 `data.db`，导出文件通过浏览器下载到本地。
